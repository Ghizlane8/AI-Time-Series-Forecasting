# 📈 Time Series Forecasting using Machine Learning

A Data Science project focused on forecasting and predictive analytics using Time Series analysis and Machine Learning techniques.

This project demonstrates how to preprocess temporal data, analyze trends, train forecasting models, and generate future predictions using Python and Data Science tools.

---

## 📌 Project Overview

The objective of this project is to build a forecasting system capable of predicting future values based on historical time series data.

The notebook includes:
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Time series visualization
- Trend and seasonality analysis
- Forecast model training
- Prediction generation
- Performance evaluation

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/Ghizlane8/Forecasting-Project.git
```

Go to the project folder:

```bash
cd Forecasting-Project
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```



## ▶️ Usage

Open the notebook:

```bash
Forecasting.ipynb
```

Run all cells to:
- Load the dataset
- Analyze time series data
- Train forecasting models
- Generate predictions
- Visualize forecasting results
